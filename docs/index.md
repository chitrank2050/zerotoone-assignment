## 🏛️ Project Vision

The AI Audience Builder is designed to bridge the gap between natural language intent and deterministic advertising signals. By leveraging **Gemini AI** and a high-density **Taxonomy Engine**, it empowers planners to build precise, reachable audience segments through a conversational interface.

## 🛡️ Core Pillars

- **Zero-Drift Execution**: Perfect type synchronization across the monorepo boundary.
- **Principal-Grade Hygiene**: Strict linting, type-safety, and automated testing.
- **AI Sovereignty**: Controlled, manual validation of all AI-generated segments.
- **Observability**: End-to-end request tracing and performance logging.
