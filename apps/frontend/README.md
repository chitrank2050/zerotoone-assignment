# AI Audience Builder - Frontend

The high-performance UI for building and estimating AI-driven advertising segments.

## 🏛️ Architecture

A modern **React 19** application built with **Vite** and **TypeScript**, focused on real-time AI interactions and reactive state management.

### ✨ Key Features

- **Real-time Chat**: Interactive audience description via Gemini 1.5.
- **Dynamic Estimation**: Instant reachability counts for targeting signals.
- **Session Management**: Persistent history of audience builds.
- **Premium UI**: Meterplex-standard aesthetic with glassmorphism and smooth transitions.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Premium Custom Design)
- **Icons**: Lucide React
- **Types**: Shared from `@audience-builder/shared`
